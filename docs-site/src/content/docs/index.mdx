Chronify ist eine selbstgehostete Zeiterfassungs-PWA für kleine Teams:
Live-Timer, wöchentlicher Stundenzettel, Pausen-Regeln nach ArbZG §4,
Überstunden-Tracking, Urlaubs-Workflow, Krankmeldungen, Admin-Backend,
DSGVO-Tooling, Reports und ein NFC-Kiosk.

Die Referenz-Bereiche (Datenmodell, API-Endpunkte, Environment-Variablen)
werden bei jedem Build automatisch aus dem Code generiert —
[source](https://github.com/2TAP2B/chronify).
